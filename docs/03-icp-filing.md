# 03 · 备案话术与流程

备案卡在措辞上。同一个产品，换个说法就能过。

## 一、备案在流程里的位置

```
注册 → 备案（当天就提）→ 开发 → 提审 → 审核通过 → 发布
```

发布 = max(代码审核过, 备案过)。 备案是唯一真正的瓶颈，7~20 个工作日，最长 1 个月。

后台原文：
> 备案可与小程序代码开发并行，**在小程序上架发布前完成即可**。

但现实里有一道坎：**没备案，提审按钮可能是灰的。**
所以「可以和开发并行」不等于「可以晚点做」。

规则：注册账号当天就把备案提上去。

## 二、先查身份证有效期（最先做的一件事）

真实案例：一个已上线的小程序，备案被注销，原因是微信通知里写的一条：

> 管理员个人**身份证过期**或工商主体经营状态异常

先去翻你的身份证，看有效期到哪天。

```
已过期 / 半年内到期 → 先去换证
否则新备案照样会被驳回，或者通过后被事后注销
```

备案是实名绑定身份证的，身份证一过期，管局就会清掉备案。

## 三、备案九步

| 步骤 | 做什么 | 等多久 |
|---|---|---|
| 1 | 登录 mp.weixin.qq.com，侧边栏「设置 → 小程序备案 → 新增备案」 | — |
| 2 | 填主体信息（个人：姓名、身份证号、证件住所、通讯地址、手机、邮箱） | — |
| 3 | 填小程序信息（名称、AppID、**服务类目**） | — |
| 4 | 人脸核验 + 签《互联网信息服务承诺书》 | — |
| 5 | 提交 → 微信初审 | **1~6 个工作日**（周末不算） |
| 6 | ⚠️ **工信部短信核验** | 收到后 24 小时内必须做完，超时作废重来 |
| 7 | 省通信管理局终审 | **1~20 个工作日，不能催** |
| 8 | 拿到备案号 `吉ICP备XXXXXXXX号-X` | 自动同步，无纸质证书 |
| 9 | 具备发布条件 | — |

最快约 1 周，正常 2~3 周，慢则 1 个月。

### 准备材料

| 材料 | 注意 |
|---|---|
| 身份证正反面照片 | 白天自然光平铺拍，**不开闪光灯**，四角完整入镜，无遮挡无反光 |
| 本人实名手机号 | 必须能收工信部 12381 短信 |
| 常用邮箱 | — |
| 通讯地址 | **精确到门牌号**：X省X市X区X街道X小区X栋X单元XXX室 |
| 应急联系电话 | 可填亲友手机号，**不能与管理员手机号相同** |

**备案全程免费。** 微信、工信部、通管局都不收费。（微信认证那 30 元是另一件事，见 08 文档。）

## 四、真实驳回复盘（最关键的一节）

### 被驳回的原文备注

```
该小程序功能为将图片压缩到指定大小。适合报名照片、电商主图、邮件附件……
```

**问题出在这三个词：**

| 词 | 为什么致命 |
|---|---|
| **电商主图** | 最致命，直接暗示**经营性** |
| **报名照片** | 隐含「代办证件照」的服务性质 |
| **邮件附件** | 单独看没事，但和前两个凑一起，整体读起来像「给商家/求职者提供的服务」 |

驳回理由原文：
> 小程序备注不符合个人性质，涉及企业或经营性

### 备案审的是什么

备案审的是「你是不是在拿它做生意」。

个人备案的小程序只能写「个人自用 / 学习 / 便民工具」性质，**不能有半点商用联想。**

### 改后的定稿（可直接套用）

```
本小程序为个人开发者的图片处理工具，用于将本地图片压缩至指定大小。
图片全程在用户设备本地处理，不上传服务器，不涉及任何交易、付费或经营活动。
```

四条改动逻辑（照这个逻辑改你的）

```
1. 删掉所有场景词 —— 报名照片 / 电商主图 / 邮件附件，一个都别留，
那是在给审核员递刀
2. 加「个人开发者」—— 明示个人性质
3. 加「全程本地处理、不上传服务器」—— 与隐私指引措辞一致
4. 加「不涉及任何交易、付费或经营活动」—— 正面回答驳回意见
```

> **通用规律**：给微信写任何文字（备注 / 简介 / 版本描述），
> 凡是能联想到「牟利」的词都要删掉。写「便民工具」能过，写「电商主图」必死。

## 五、禁词表

```
交易类
电商 / 商城 / 店铺 / 交易 / 售卖 / 销售 / 商品 / 订单

付费类
付费 / 收费 / 会员 / 订阅 / 充值 / 内购 / 购买

推广类
广告 / 推广 / 引流 / 变现 / 盈利 / 商业 / 营销

身份类
服务商 / 平台 / 代运营 / 接单 / 工作室

素材类
主图 / 详情页 / 营销素材 / 商用素材 / 商品图

场景类（最容易被忽略）
报名照片 / 考试照片 / 卖家 / 商家 / 专业 / 代办
```

**判断口诀**：写「这个功能做什么」，不写「谁用它来做什么」。

## 六、三套备注模板

### 模板 A · 纯工具类（最稳）

```
本小程序为个人自用的图片处理工具，提供图片压缩、格式转换、尺寸调整等
本机处理功能。所有处理在用户设备本地完成，不上传服务器，不收集用户个人信息，
不涉及商品交易、付费服务、广告投放等任何经营性活动，无用户注册与内容发布功能。
```

### 模板 B · 信息查询类

```
本小程序为个人学习用途的信息查询工具，提供常用数据对照与换算查询。
数据为公开静态资料，不含用户生成内容，无评论、发布、分享功能，
不涉及商品交易与付费服务，不收集用户个人信息。
```

### 模板 C · 游戏/娱乐类（走小游戏通道）

```
本小程序为个人自用的休闲小游戏，无内购、无虚拟支付、无广告投放，
不涉及商品交易与付费服务，不收集用户个人信息，仅供个人娱乐使用。
```

## 七、五个高频驳回坑

| # | 坑 | 怎么避 |
|---|---|---|
| 1 | 身份证照片模糊/反光/缺角 | 自然光平铺拍，四角完整 |
| 2 | **备注涉及经营性** | 按第四节逻辑重写，删所有场景词 |
| 3 | 服务类目与实际功能不符 | 先定功能再选类目，简介别超类目范围 |
| 4 | 通讯地址没精确到门牌号 | 写到「X栋X单元XXX室」 |
| 5 | **忘记 24 小时内做短信核验** | 收到立刻做，别拖 |

## 八、被驳回之后

```
✅ 备案驳回 ≠ 从头排队
改信息重提交属于原申请的修正，通常比首次提交快

✅ 只改被驳回的那一项
⚠️ 服务内容 / 名称 / 人脸核验别动，只改备注

✅ 管局可能打电话回访
保持手机畅通 —— 漏接容易被驳回
```

## 九、备案与小程序信息必须一致

官方只写了一句，但后果很重：
> 备案信息与小程序信息不一致时，平台可警告、封禁功能、强制注销备案。

推论：**备案过了之后，不要随便改名。**

要改的话，顺序必须是：
```
确认新名称能过 → 改名称 → 同步改备案 → 再提审
```

**反过来想**：如果你决定不改名（用现有已通过的名字），
**备案一个字都不用动**，直接跳过「改名审核 + 变更备案」两段等待（管局上限 20 工作日）。

这是很多人的最优解：先用现有名字把版本发出去，改名以后再说。

## 十、提交前自查

```
□ 身份证有效期在半年以上
□ 备注里没有任何禁词表里的词
□ 没有出现任何使用场景描述（电商/报名/商用/卖家/商家）
□ 加了一句「不涉及任何交易、付费或经营活动」
□ 地址精确到门牌号，与身份证一致
□ 应急联系电话与管理员手机号不同
□ 手机号能接工信部 12381 短信
□ 注册当天就提交，没拖到开发完
```
