# 04 · 隐私与数据

这一关有个反直觉的事实：**你申请得越少，越容易过。**
但还有一个更反直觉的：配好了不代表生效，审核通过才生效。

## 一、官方规则原文

《常见拒绝情形》3.4-1：
> 在收集和使用用户任何数据时，必须明确告知用户该数据的用途，确保经过用户明确同意和授权，并应在用户同意和授权的范围内进行合理使用。在用户注销账号后应相应删除相关数据。

3.4-2：不得请求或诱导输入微信用户名或密码。
3.4-4：不得出售、转交、交易、越权披露、泄露用户数据。
3.4-5：不得在未经授权同意的情况下显示用户相关数据（头像、昵称）。
3.4-7：有位置追踪功能必须提供退出该追踪的功能和明确指示。

## 二、核心判据：不申请就不审

平台的隐私审核**跟着接口走**。没调隐私接口，就没有隐私审核这一项。

所以先确认要不要这些权限，再考虑隐私政策怎么写。

## 三、需要隐私授权的高危接口清单

```
身份类
wx.getUserProfile        获取用户信息（头像昵称）
wx.getUserInfo           旧版获取用户信息
wx.getPhoneNumber        获取手机号
wx.login + 后端换 openid  不算隐私接口，但会拿到用户标识

位置类
wx.getLocation           获取位置
wx.chooseLocation        选择位置
wx.onLocationChange      持续定位（审核最严）
wx.startLocationUpdate   开启定位

相册/摄像头
wx.chooseImage           选图（旧版）
wx.chooseMedia           选图/视频
wx.chooseVideo           选视频
wx.saveImageToPhotosAlbum  存图到相册
wx.saveVideoToPhotosAlbum  存视频到相册
wx.createCameraContext   相机

通讯录/其他
wx.chooseAddress         收货地址
wx.addPhoneContact       添加手机联系人
wx.getClipboardData      读剪贴板
```

**搜法**
```bash
grep -rn "getUserProfile\|getUserInfo\|getLocation\|chooseImage\|chooseMedia\|saveImageToPhotosAlbum\|getPhoneNumber\|chooseAddress\|getClipboardData" --include=*.js --include=*.ts .
```

## 四、接口 ↔ 后台声明对应表（照这个勾）

| 代码里的接口 | 后台要声明的隐私类型 |
|---|---|
| `wx.chooseMedia` / `wx.chooseImage` | 收集你选中的照片或视频信息 |
| `wx.saveImageToPhotosAlbum` | 使用你的相册（仅写入）权限 |
| `wx.authorize({scope:'scope.camera'})` / `<camera>` | 访问你的摄像头 |
| `wx.getUserProfile` | 收集你的昵称、头像 |
| `wx.getLocation` | 收集你的位置信息 |
| `wx.getClipboardData` | 收集你的剪切板信息 |
| `wx.getPhoneNumber` | 收集你的手机号 |

⚠️ `wx.chooseMedia` 在官方对应表里**只挂在「照片或视频信息」下**，「摄像头」那一栏没列它。
所以只勾「照片或视频信息」就能让 chooseMedia 跑起来。勾摄像头是因为代码里 `sourceType` 带了 `'camera'`，属于如实申报，不是必须。

## 五、最要命的一条：审核通过后才生效

《用户隐私保护指引填写说明》原文：
> 入口1：「账号设置 - 服务内容声明 - 用户隐私保护指引 - 去完善」
> 开发者可随时基于小程序现网版本进行隐私协议的完善或更新，**审核通过后即可生效**。

所以后台显示「审核中」时，接口一定报这个错：

```
chooseMedia:fail api scope is not declared in the privacy agreement
errno: 112
```

翻译：这个接口涉及的个人信息，你没在指引里声明过，**或者声明了但还没生效**。

这不是 bug，不是缓存，不是基础库版本问题。
清缓存、重新编译、换手机、更新开发者工具 —— **四招全部无效**，只能等审核通过。

通过后约 **5 分钟**生效，回开发者工具重新编译再试。

唯一判断标准：后台指引状态是不是「已通过」。 不是「已提交」、不是「审核中」。

## 六、⚠️ 一条被广泛传错的配置

网上（包括很多教程）都说要在 `app.json` 里加：
```json
"__usePrivacyCheck__": true
```

这个开关只在 2023-09-15 ~ 2023-10-17 的过渡期有效，现在（2026 年）早已失效。
设成 `false` 也没用，设成 `true` 也不起任何作用。别在这上面浪费时间。

2026 年真正决定能不能调接口的，只有后台那份《用户隐私保护指引》是否审核通过。

## 七、填表模板（直接照抄）

用途说明写得越具体越容易过，**别写「用于改善服务」这种空话**。

### ① 选中的照片或视频信息（`wx.chooseMedia` 靠这一项）

> 用于读取你主动选择并提交的图片，在本机完成压缩处理后返回结果。图片不会上传至服务器，不会提供给任何第三方，也不会用于其他用途。

### ② 摄像头（代码里 `sourceType` 带 camera 才需要）

> 用于拍摄照片并直接压缩。拍摄的照片仅在本机处理，不会上传至服务器。

**不想声明这一项？** 把 `sourceType: ['album', 'camera']` 改成 `sourceType: ['album']`，只保留从相册选。

### ③ 相册（仅写入）权限（`wx.saveImageToPhotosAlbum` 靠这一项）

> 用于将压缩后的图片保存到你的手机相册。不会读取、修改或删除相册中的其他任何内容。

### ④ 剪切板（`wx.getClipboardData` 靠这一项）

> 用于读取你主动复制的文本内容并填入输入框，不会上传或用于其他用途。

### 纯本地小游戏（不采集任何个人信息）

「是否采集用户个人信息」选 **「否」**，然后在设备权限声明里写：
```
本地存储（wx.setStorageSync）：用于记录游戏关卡进度与金币
振动反馈（wx.vibrateShort）：用于模拟物理触感
```

## 八、操作步骤（路径别走错）

```
1. 浏览器打开 mp.weixin.qq.com，用小程序管理员微信扫码登录
2. 左侧菜单「管理 → 账号设置」（进去后页面标题就是「设置」）
⚠️ 中间没有「基本设置」这一层
3. 找「服务内容声明」→「用户隐私保护指引」→ 点「去更新」/「修改」
4. 按上面的模板逐项勾选 + 填用途说明
5. 提交 → 等审核（通常 1~3 个工作日）
6. 等状态从「审核中」变「已通过」
7. 通过后约 5 分钟 → 回开发者工具重新编译 → 真机验证
8. 全流程走通 → 才去点「提交审核」
```

## 九、⚠️ 提审时那一栏必须选「已采集」

提审表单里有「用户隐私保护指引设置」这一栏。

必须选「采集用户隐私」并如实填写，不要图省事选「未采集」。

官方原文：
> `{ "errMsg": "A:fail appid privacy api banned" }`
> 使用到了 A 隐私接口，但是开发者在 mp 提审时勾选了「未采集隐私」，或者未声明隐私协议，
> **被平台回收了接口调用权限**。

一旦权限被回收，报错会从 `scope not declared` 变成 `api banned`，处理起来更麻烦。

## 十、报错对照表

| 现象 | 原因 |
|---|---|
| 提交后仍报 `scope not declared` | **指引还在「审核中」（未生效）**，唯一解法是等 |
| 提示「请先完成主体信息登记」 | 小程序注册流程没走完 |
| 选图正常，但保存到相册报错 | 漏勾「相册（仅写入）权限」 |
| 选图正常，但拍照报错 | 漏勾「摄像头」 |
| 配置页找不到入口 | 后台菜单结构变了，直接搜「隐私」 |
| 报错变成 `api banned` | 提审时勾了「未采集」，权限被回收 |

## 十一、两个容易漏的连带问题

### 漏项 1：存相册也算「处理用户数据」

很多人以为「我只是把图存到相册，没上传，不算收集」。
实际：`saveImageToPhotosAlbum` 是隐私接口，必须配隐私指引。而且它同时踩 5.18（见 05 文档）。

### 漏项 2：没授权就显示了头像昵称

违反 3.4-5。常见写法是登录后直接把 `userInfo.avatarUrl` 渲染出来，但授权被用户拒绝了。
**必须做兜底**：没拿到授权就显示默认头像 + 默认昵称，不能显示空或报错。

## 十二、提交前自查

```
□ 跑过 grep，列出所有隐私接口调用
□ 每个接口都能对应到后台勾选的一项（对照第四节的表）
□ 后台指引状态是「已通过」（不是「审核中」）
□ 通过后真机全流程走通过一遍
□ 提审表单隐私栏选「采集用户隐私」
□ 用户拒绝授权时，功能降级不崩溃
□ 没有在未授权情况下显示头像/昵称
□ 有定位功能的话，提供了关闭开关
□ 有账号体系的话，有可发现的「退出」入口（官方 3.5-5）
```
