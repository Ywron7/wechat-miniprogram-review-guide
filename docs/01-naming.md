# 01 · 名称与主体

名称是提审第一项，也是驳回最快的项——**当天驳回，不是 7 个工作日**。

## 一、官方规则原文（审核员手里的标准）

《微信小程序平台常见拒绝情形》1.1-2：
> 含有商业化用语的、热门小程序名称、「国家级」「最高级」等新广告法明令禁止或其他无关的词语。

《微信小程序平台常见拒绝情形》1.2.1-3：
> 小程序名称不能以电话、邮件、日历、小游戏等广义归纳类、斗地主、麻将等通用游戏名称类、或者其他普遍且不具有识别性词语来命名。示例：名称不是单词汇，必须是两个词以上的组合，当无法判断时，审核人员可主观判断。

最后那句「审核人员可主观判断」是全篇最狠的一句。它意味着：没有 100% 确定的边界，只有概率。 你要做的是把概率拉到足够高，不是去找那条线在哪。

## 二、两种驳回理由，逐字对照

同一个项目、连续两次，官方驳回理由原文：

| 提交 | 申请名称 | 驳回理由（后台原文） |
|---|---|---|
| 第一次 | 图片转换免费工具箱 | 涉及**营销商业化词**，命名不规范 |
| 第二次 | 图片转换工具箱 | 涉及以**通用词**命名 |

两次都是当天驳回。

拆开看，官方其实给了两个独立的词表：

营销商业化词表（1.1-2 管）
```
免费 / 永久免费 / 最 / 最好 / 第一 / 首家 / 顶级 / 国家级
官方 / 正版 / 授权 / 认证 / 一键 / 神器 / 必备 / 破解
```

通用词表（1.2.1-3 管）
```
工具 / 工具箱 / 助手 / 大全 / 导航 / 查询 / 平台 / 中心
转换 / 压缩 / 计算 / 生成 / 处理 / 识别
```

**判定公式**
```
名称 = 通用功能词 + 通用品类词  →  必驳（通用词命名）
名称 = 通用功能词 + 营销词 + 品类词  →  必驳（营销商业化词）
名称 = 品牌词/造词 + 功能词  →  可过
```

「图片转换工具箱」= 通用功能词（图片转换）+ 通用品类词（工具箱）= 第二个公式，必驳。

## 三、三种能过的命名结构

### 结构 A：造词 + 功能词（最稳，零成本）

把一个常用字组合成不存在的词，再接功能词。

```
小图快压        ← 已验证通过：已过审、已备案、已认证、线上可搜
小图快压图片转换  ← 品牌词 + 功能词，保住原名同时补功能描述
```

为什么「快压」能过：「快压」不是现成词，有显著性；「小图」也是组合。整个名字不是「通用功能词 + 通用品类词」的结构。

**可用造词手法**
- 缩合：快压 / 秒传 / 极扫 / 净图
- 拟人：图小匠 / 压小工 / 画小七
- 拟物：图匣子 / 像素罐 / 图纸盒
- 叠字：小小压 / 图图转

### 结构 B：自有品牌词 + 功能词

你已经有的名字（哪怕没注册商标），只要不是通用词，就能当前缀。

```
小图快压图片转换
小图快压压缩
```

注意：这里的功能词必须是**描述性**的，不能是第二个通用品类词。「小图快压工具箱」里「工具箱」还是通用词，仍然有风险。

### 结构 C：人名/昵称 + 功能词

```
阿鑫的图片压缩
```

个人主体、无商标时，昵称类前缀的显著性来自「指向特定主体」，通常能过。缺点是不可扩展、不好记。

## 四、「上传商标注册证」这条通道，对个人等于不存在

官方在驳回通知里给的异议通道是：上传《商标注册证》或商标授权使用书。

**对零预算个人，这条路是假的：**
- 个人申请商标要 6~12 个月
- 要花钱（官费 + 代理费）
- 拿到证之前，名称改不了

所以别在驳回后想「我去申诉」。申诉不能推翻通用词判定，只有商标能。 你能做的只有改名。

## 五、改名额度：提交前必须先看这一行

后台名称那一行写着：
> 当前还能修改 N 次
> 改名次数将在自然年 1 月 1 日和微信认证审核通过后重置为 2 次

驳回到底占不占额度，官方没写。 官方没写，就是未知。

所以规则是：

> 任何一次提交名称之前，先截图看 N 是几。

如果两次驳回已经把额度吃光（N=0），就要等到明年 1 月 1 日。那意味着「改名」这件事在本年度直接结束，整个命名方案要按现有名字重排。

## 六、名称之外的连带影响（容易漏）

名称不只影响后台那一个字段。改一次名，这些地方会不同步：

| 位置 | 是否受命名规范约束 | 风险 |
|---|---|---|
| app.json 的 `navigationBarTitleText` | 否 | 但出现「免费」等词 = 白送审核抓手 |
| 首页 banner 文案 | 否 | 同上 |
| 分享标题 | 否 | 同上，且涉及 3.2-1 诱导分享 |
| 关于页 | 否 | 名称与实际服务对不上会被问 |

**处理原则**：名称定了之后，一次性把 4 处显示名同步，别分批改。分批改 = 多次提审 = 多次排队。

## 七、提交前最后一遍自查

```
□ 名字里没有营销词表里的任何一个词
□ 名字里没有通用词表里的品类词（工具/助手/大全/导航/平台）
□ 名字是「造词/品牌词 + 功能词」，不是「功能词 + 品类词」
□ 名字里没有特殊行业词（社区/保险/教育/医疗/金融）
□ 名字和简介的意思一致，简介里能找到名字里的词
□ 后台「还能修改 N 次」已截图，N ≥ 1
□ app.json / banner / 分享标题 / 关于页 4 处显示名已同步
```
