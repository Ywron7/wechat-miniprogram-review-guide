# 07 · 官方条款索引

写申诉、跟审核沟通、判断某个做法行不行，**引条款号比讲道理有用**。

来源：《微信小程序平台常见拒绝情形》
`developers.weixin.qq.com/miniprogram/product/reject.html`

---

## 1. 账号基本信息

| 条款 | 原文要点 | 对应闸 |
|---|---|---|
| 1.1-1 | 名称、简介、logo、服务范围、服务标签不得侵犯他人权益（著作权、商标权、肖像权、名誉权），不得含不属于本主体的品牌或商标 | 名称 |
| 1.1-2 | 不得含**商业化用语**、热门小程序名称、「国家级」「最高级」等新广告法明令禁止或其他无关词语 | 名称 |
| 1.1-3 | 不得含政治、色情、敏感、暴力血腥、恐怖、违法内容 | 名称 |
| 1.2.1-1 | 简介需明确介绍功能点，不能用模糊词义表达 | 名称 |
| 1.2.1-2 | 名称与简介意思必须关联一致，与实际功能一致，不含与功能无关的搜索热词 | 名称 |
| 1.2.1-3 | 名称不能以**广义归纳类**（电话、邮件、日历、小游戏）、通用游戏名、其他**普遍且不具有识别性**词语命名。名称不是单词汇，必须两个词以上组合，**审核人员可主观判断** | 名称 |
| 1.2.2-1 | logo 清晰度不够不予通过 | 名称 |
| 1.2.2-2 | logo 应与名称、简介一致 | 名称 |

| 1.2.3 | 服务标签应与服务范围一致，不能超出 | 类目 |

## 2. 服务类目审核

| 条款 | 原文要点 | 对应闸 |
|---|---|---|
| 2.1-1 | 类目对应页面的核心内容必须与该类目一致 | 类目 |
| 2.1-2 | 必须保证用户在该页面能使用该类目服务，**不得隐藏，不得多次跳转** | 类目 |
| 2.1-3 | **一旦选择游戏类目，不可修改为其他类目** | 类目 |
| 2.2 | 类目对应页面链接须能正常打开，不加载非法信息、恶意色情广告、侵权内容 | 类目 |

## 3. 整体审核规则

### 3.1 基本功能审核规范

| 条款 | 原文要点 | 对应闸 |
|---|---|---|
| 3.1-1 | 实际提供的功能点需与简介一致 | 名称 |
| 3.1-2 | 所有类目功能必须**首页直达或经 2 次点击到达** | 类目 |
| 3.1-3 | 不得提供尚未开放的服务，不得超出已开放类目库 | 类目 |
| 3.1-4 | 隐藏/付费功能不得含违规内容，须提供可完整体验的测试号 | 提审节奏 |
| 3.1-5 | 功能应具有使用价值，**不能过于简单**（只有一个页面一个按钮） | 提审节奏 |
| 3.1-6 | 未经授权不得提供与微信客户端相同或类似功能（朋友圈、漂流瓶） | 内容安全 |
| 3.1-7 | 未经授权不得展示推荐第三方小程序（不能做导航、互推、排行榜） | 内容安全 |
| 3.1-8 | 使用功能不得以关注或使用其他号为条件 | 内容安全 |

### 3.2 页面内容审核规范

| 条款 | 原文要点 | 对应闸 |
|---|---|---|
| 3.2-1 | 不得有**诱导分享、诱导添加、诱导关注公众号、诱导下载**；含明示暗示分享的文案图片按钮浮层弹窗 | 内容安全 |
| 3.2-2 | 页面主要为营销或广告用途将被拒（空白广告位、招商广告、悬浮广告、广告占比超 50%、广告遮挡功能） | 内容安全 |
| 3.2-3 | 不得有误导、引发恐惧、严重破坏体验或损害用户利益的谣言类内容 | 内容安全 |
| 3.2-4 | **不能存在测试类内容**（算命、抽签、星座运势） | 内容安全 |
| 3.2-5 | 不得有虚假、欺诈内容（虚假红包、虚假活动、仿冒腾讯或他人业务） | 内容安全 |
| 3.2-6 | 不得含骚扰、广告、垃圾信息 | 内容安全 |
| 3.2-7 | 不得违反与腾讯签订的任何协议 | 内容安全 |
| 3.2-8 | 八类违法内容（政治、色情、暴力、赌博、未成年等） | 内容安全 |
| 3.2-9 | **小程序内的图片上不能含有广告、网址或虚假内容** | 内容安全 |
| 3.2-10 | 代替用户发表、发送、转交任何内容前，必须征得明确同意和授权 | 内容安全 |
| 3.2-11 | **服务提供者必须提供过滤不当内容的措施**（对发布色情、赌博等违法违规词汇进行过滤提示） | 内容安全 |
| 3.2-12 | 不得误导暗示与腾讯有合作、投资、背书关系 | 内容安全 |

### 3.3 可用性和完整性

| 条款 | 原文要点 | 对应闸 |
|---|---|---|
| 3.3-1 | 须是**完成品**，可打开可运行，不可为测试版（不可运行、崩溃、闪退、按钮无响应、文字不完整） | 提审节奏 |
| 3.3-2 | 本身崩溃或造成微信崩溃将被拒 | 提审节奏 |
| 3.3-3 | 存在严重 Bug（无法添加打开、无法返回退出、卡顿严重）将被拒 | 提审节奏 |
| 3.3-4 | 有账号体系须提供**测试号**（账号+密码，可体验所有功能） | 提审节奏 |

### 3.4 用户隐私和数据安全

| 条款 | 原文要点 | 对应闸 |
|---|---|---|
| 3.4-1 | 收集使用任何数据必须明确告知用途、经明确同意授权、范围内使用，注销后删除 | 隐私 |
| 3.4-2 | 不得请求或诱导输入微信用户名或密码 | 隐私 |
| 3.4-3 | 不得将搜索小程序功能加入小程序 | 隐私 |
| 3.4-4 | 不得出售、转交、交易、越权披露、泄露用户数据 | 隐私 |
| 3.4-5 | **未经授权不得显示用户头像、昵称等数据** | 隐私 |
| 3.4-6 | 不得要求用户越狱/ROOT 后使用 | 隐私 |
| 3.4-7 | 有位置追踪功能必须提供退出该追踪的功能和明确指示 | 隐私 |

| 3.5-3 | 不得安装或运行其他可执行代码 | 提审节奏 |

## 怎么用这份索引

**写申诉时**：引具体条款号 + 说明你的做法如何满足该条款。
```
例：本小程序未调用任何用户信息接口（对应 3.4-1 无收集行为），
    输出仅写本机相册，不存在传播链路（对应 3.2-11 无需过滤场景）。
```

**判断某个做法行不行时**：先在索引里搜关键词，找到条款原文，再决定。
不要凭「我见过别人这么做」判断——别人能过，不代表你能过（官方原话：审核人员可主观判断）。
