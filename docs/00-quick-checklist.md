## ① 名称

```
□ 已核对后台注册名称与商业宣传表述；没有把单字「最」作为禁词
□ 没有通用品类词：工具 / 工具箱 / 助手 / 大全 / 导航 / 查询 / 平台
□ 结构是「造词或品牌词 + 功能词」，不是「功能词 + 品类词」
□ 没有特殊行业词：社区 / 保险 / 教育 / 医疗 / 金融
□ 简介里能找到名称里的词，两者意思一致

## ④ 隐私

```
□ 跑过 grep，列出所有隐私接口调用：＿＿＿＿＿＿＿＿
□ 每个接口都对应到后台隐私指引里勾选的一项
□ 对应版本的信息类型已声明并生效，用户同意状态已同步
□ 通过后真机全流程走通过一遍
□ 提审表单隐私栏选「采集用户隐私」（不是「未采集」）

## ⑤ 内容安全（5.18）

```
□ 产品会处理用户提供的内容（图片 / 文字 / 音频 / 视频）：☐ 会　☐ 不会
□ 处理结果会离开小程序（存相册 / 导出 / 分享）：☐ 会　☐ 不会
□ 根据实际用户内容、展示、保存和传播路径核查过滤机制，不按接口名称直接判违规
□ 没有任何用户可见的内容列表（广场 / 历史 / 他人作品）
□ 没有用户输入文字生成图片的功能（水印 / 字幕 / 文字转图）
```

> 依据：《常见拒绝情形》3.2-11、《运营规范》5.18
> 官方按违规程度阶梯处置；五项永久限制是本项目的个案通知结果。

## ⑥ 提审节奏

```
□ 没有「即将上线」「敬请期待」「功能开发中」字样
□ 不是「只有一个页面一个按钮」的极简品
□ 有账号体系 → 已准备测试号（能体验全部功能）
□ 真机验证 9 项已过（冷启动 / 逐页 / 返回 / 按钮 / 空态 / 权限 / 输入 / 分享 / 弱网）
□ 用没登录过的微信账号测过一遍
□ 截图 3~5 张，每张不同、顶栏名称清晰、单张 60KB~5MB
□ 提审时间选在工作日 9:00-11:00
□ 加急次数：个人主体每年 **1 次**，留着别用
```

> 依据：《常见拒绝情形》3.3-1（完成品）、3.3-4（测试号）、3.1-5（功能不能过简）

## 提审之后

```
□ 不动名称、不动简介、不动类目、不动 logo、不重新上传代码
□ 出结果当天处理：一次只改一项
□ 审核通过 → 立刻点「提交发布」（拖着不发，后续提审可能让通过的版本消失）
```
