# 备案备注模板

判定标准只有一条：**这段文字能不能让人联想到「你在赚钱」。**

能联想到 → 涉及经营性 → 驳回。
不能联想到 → 过。

个人主体只能写这三类：**个人自用 / 个人学习 / 便民工具**。

---

## 模板 A · 纯工具类（最稳，优先用这个）

```
本小程序为个人自用的图片处理工具，提供图片压缩、格式转换、尺寸调整等
本机处理功能。所有处理在用户设备本地完成，不上传服务器，不收集用户个人信息，
不涉及商品交易、付费服务、广告投放等任何经营性活动，无用户注册与内容发布功能。
```

**为什么能过**：每一句都在排除一个驳回点——不交易、不收费、不投放广告、不收集信息、无 UGC。

**改法**：把「图片压缩、格式转换、尺寸调整」换成你实际的功能，其余原样保留。

---

## 模板 B · 信息查询类

```
本小程序为个人学习用途的信息查询工具，提供常用数据对照与换算查询。
数据为公开静态资料，不含用户生成内容，无评论、发布、分享功能，
不涉及商品交易与付费服务，不收集用户个人信息。
```

---

## 模板 C · 游戏/娱乐类（走小游戏通道）

```
本小程序为个人自用的休闲小游戏，无内购、无虚拟支付、无广告投放，
不涉及商品交易与付费服务，不收集用户个人信息，仅供个人娱乐使用。
```

---

## 禁词表（出现即驳回）

```
交易类
  电商 / 商城 / 店铺 / 交易 / 售卖 / 销售 / 商品 / 订单

付费类
  付费 / 收费 / 会员 / 订阅 / 充值 / 内购 / 购买

推广类
  广告 / 推广 / 引流 / 变现 / 盈利 / 商业 / 营销

身份类
  服务商 / 平台 / 代运营 / 接单 / 工作室

素材类
  主图 / 详情页 / 营销素材 / 商用素材 / 商品图
```

### 最危险的：看起来无害的场景词

真实案例：一个图片压缩工具，备注写了「电商主图压缩」——本意只是说明使用场景，被判涉及经营性，驳回。

**改法：场景词全部换成功能词。**

```
❌ 电商主图压缩 / 商品图片优化 / 卖家批量处理 / 商用素材生成
✅ 图片压缩 / 尺寸调整 / 格式转换 / 图片裁剪
```

**判断口诀**：写「这个功能做什么」，不写「谁用它来做什么」。

---

## 被驳回后的三种改法

| 驳回原因 | 真实含义 | 改法 |
|---|---|---|
| 涉及经营性 | 措辞里有赚钱的联想 | 按禁词表全清，换成模板 A |
| 信息不完整 | 地址/主体信息有缺 | 地址精确到门牌号，与身份证一致 |
| 内容与主体不符 | 备注写的和实际功能对不上 | 备注只写你确实做了的功能 |

---

## 提交前自查

```
□ 备注里没有任何禁词表里的词
□ 没有出现使用场景描述（电商/商用/卖家/商家/工作室）
□ 地址精确到门牌号，与身份证一致
□ 备注里写的功能 = 小程序实际有的功能
□ 手机号能接短信/电话核验
□ 注册当天就提交，没拖到开发完（备案 7~20 天，是整条链最长的一段）
```

---

## 一条容易被忽略的连带风险

备案信息与小程序信息必须一致。官方原文：
> 备案信息与小程序信息不一致时，平台可警告、封禁功能、强制注销备案。

所以备案过了之后，**不要随便改名**。

要改的话，顺序必须是：
```
确认新名称能过 → 改名称 → 同步改备案 → 再提审
```
不要反过来。
