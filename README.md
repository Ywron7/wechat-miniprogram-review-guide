**微信小程序审核驳回、备案被拒、5.18 内容安全限制的自查清单与预检脚本。**

不教写代码。只干一件事：**在你点「提交审核」之前，把能杀掉你的那几项找出来。**

提审失败的成本不是重做，是排队时间——一次驳回 = 一天，一次永久限制 = 整条线归零。

## 它能做什么

跑一条命令，输出一份按六道闸分组的报告：

```console
$ python scripts/precheck.py ./my-miniprogram

# 小程序提审预检报告

- 扫描目录：`./my-miniprogram`
- 项目配置：`app.json`

## 总览

**FAIL 2 ｜ WARN 5 ｜ PASS 4**

> ⚠️ 存在 FAIL 项，**不要提审**。提审不会帮你发现问题，只会帮你排队一天。

## 名称

❌ **[FAIL]** 标题含营销商业化词：图片转换免费工具箱
  - 位置 app.json window.navigationBarTitleText，命中 ['免费', '工具箱']
  - 改法：官方 1.1-2 禁止商业化用语。页面标题虽不受命名规范约束，
          但出现这些词等于给审核白送抓手，建议全部替换

## 隐私

⚠️ **[WARN]** 调用了 chooseMedia（选图/视频）
  - 出现在：pages/index/index.js
  - 改法：必须配隐私指引 + 授权弹窗，且后台「用户隐私保护指引」要审核通过

## 内容安全

❌ **[FAIL]** 产品形态落在 5.18 射程内：既产出新内容，又让内容离开小程序
  - 产出类接口 ['canvasToTempFilePath']；外流类接口 ['onShareAppMessage']
  - 改法：三条路选一条 —— 接服务端内容安全接口 / 改形态 / 不做这个形态
```

完整样例：[examples/sample-report.md](examples/sample-report.md)

脚本只做静态扫描，**不联网、不上传、不修改任何文件**。

## 30 秒开始

```bash
git clone https://github.com/CC368/wechat-miniprogram-review-guide.git
cd wechat-miniprogram-review-guide

python scripts/precheck.py <你的小程序项目根目录>
```

无第三方依赖，Python 3.8+ 即可。加 `--md report.md` 可以把报告写到文件。

**支持两种项目结构**

| 类型 | 配置文件 |
|---|---|
| 原生小程序 | `app.json` |
| uni-app | `pages.json` + `manifest.json`（含 JSON5 容错，HBuilderX 生成的带注释也能读） |

**退出码**：`0` 全过或只有 WARN，`1` 存在 FAIL。可以直接挂进 CI。

|---|---|

| 名称驳回 #2 | `图片转换工具箱` → 「涉及以通用词命名」，**当天驳回** |

## 三个最反直觉的事实

**一、`__usePrivacyCheck__` 已经失效了。**

网上大量教程让你在 `app.json` 里加这个字段。它只在 2023-09-15 ~ 2023-10-17 的过渡期有效。
2026 年真正决定接口能不能调的，只有后台《用户隐私保护指引》是否**审核通过**。
状态是「审核中」时，接口一定报 `scope not declared`（errno 112）——清缓存、换手机、更新工具，四招全部无效。

**二、「本机处理、不上传服务器」不构成豁免。**

平台的安全模型三个「不看」：不看语义、不看是否上传、只看「用户内容 → 视图节点」这条链上有没有检测机制。
你不上传，不代表你没处理内容。一个纯本地的图片镜像翻转功能，照样被判 5.18。

**三、加急审核个人主体每年只有 1 次。**

网上大量文章写「3 次/年」——那是非个人主体的口径。个人主体是 **1 次/年**，别照着算。

## 适用范围与免责

**适用**
- 个人主体、无商标、零预算，第一次做微信小程序
- 已有一个能跑的代码，卡在审核/备案/隐私/内容安全
- 被驳回、被限制，需要知道下一步改什么

**不适用**
- 医疗、金融、直播、电商平台等需要前置许可的类目（个人主体基本拿不到，不在本文范围）
- 纯代码开发问题（假设你的代码已经能跑）
- 企业主体的特殊资质流程

**免责**
不保证过审。官方原文写得很清楚：「当无法判断时，**审核人员可主观判断**」。
这份指南是把概率拉到足够高，不是给你一条确定的线。
