# 小程序提审自检

1. 读取用户已提供的项目与后台材料，按当前问题定位 references/00-quick-checklist.md 中相关项。
2. 需要详细依据时读取 references/ 下对应文档，区分官方规则、个案和作者建议。
3. 输出各项 PASS / RISK / FAIL / UNKNOWN、已查依据和下一步。只有有明确证据的阻断项才标 FAIL，不把信息缺失写成通过。
4. 对影响判断的缺失信息作简短询问；不要求用户重复提供已有材料，不猜测后台状态。

隐私接口需核对对应版本的信息类型声明、生效状态及用户同意。errno 112 先补齐缺少的声明再等待生效；2023-10-17 后无需靠 `__usePrivacyCheck__` 启用隐私功能。

内容安全需核对真实用户内容、数据流和检测机制；API 名称、本地处理或一个案例的处罚都不能单独证明合规或违规。5.18 按违规程度阶梯处置。

本包提供人工清单与参考文档。需要源码静态预检和整改模板时使用 mp-review-guard 完整包。无论哪种方式，均不代替后台、开发者工具和真机验证。
